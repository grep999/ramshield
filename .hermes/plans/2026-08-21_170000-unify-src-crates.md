# Unify src/ ↔ crates/: Two-Way Integration Plan (v2)

> **For Hermes:** Execute task-by-task. Each phase ends green before next starts.
> Supersedes v1 ("src wins"). v2 = per-module merge: most advanced impl as base, port the other side's genuine advances.

**Goal:** One source of truth per domain. Each unified module = newest/most-advanced implementation as base + explicit port of the other side's superior pieces. Binary consumes crates. Deps current.

**Architecture:** Domain logic lives only in `crates/ramshield-*`. `src/` keeps binaries (`main.rs`, `cli.rs`) + glue (`engine/`, `ipc/`, `dashboard/`). Root crate depends on path deps.

## Cross-Module Integration Check (verified against real call sites)

Every merge decision validated against consumer call sites BEFORE merging:

1. **BlockReason — src 5-variant WINS, reject crate's 7.** Crate types has `Ddos, Scan, Manual, HighRps(u64), …`; src has `HighRps, SubnetBatch, ForecastAnomaly, EntropyAnomaly, ManualBlock`. Live constructors (detection:357, enforcement:242, storage:155) use src shape. Taking crate's would break every construction site. WAL stores reason as free `String` — no serde coupling. Fix types/error.rs to src variants.
2. **ConnectionEvent — identical both sides.** Verbatim copy, zero risk.
3. **BlockDecision.batch_subnet — crate IpNetwork wins** over src `[u8;3]` (v4-only). Aligns with subnet_key→(u128, IpNetwork). Adapt src detection construction site.
4. **EnforceResult.wal_lsn ALREADY EXISTS in src** — field present, never set. WAL-first port = inject `Option<Arc<Wal>>` + set existing field. Smaller than planned.
5. **Command enum (crate) confirmed dead** — only crate forecasting uses it; merged forecasting takes src `Sender<EnforceCommand>` from engine wiring (engine/mod.rs:27 channel). Enum deleted.
6. **Store API surface audited.** Src consumers need: get/insert/remove/len/inner/get_stats/get_all_blocked_ips/get_ips_in_subnet/update_subnet_index/subnet_table/reset_subnet_window/merge_subnet_window/evict_batch/record_flush/drain+push_threat_sample/ram_bytes/heap_bytes. Crate-side extra `iter()` used only by crate enforcement reconcile — src reconcile uses `get_all_blocked_ips()` instead. No iter() needed in merged Store.
7. **⚠ SubnetTable key widening REQUIRED: u32 → u128.** Crate batch aggregate returns `HashMap<u128, u32>` (IPv4 low-32, IPv6 full); src `merge_subnet_window(key: u32, …)` + `DashMap<u32, SubnetRecord>`. Porting crate batch without widening breaks compile AND drops v6 aggregation. Merged Store: `DashMap<u128, SubnetRecord>`, `merge_subnet_window(key: u128, prefix_from_IpNetwork, …)`, `subnet_prefix([u8;3])` replaced by IpNetwork metadata. THE one real schema change.
8. **atomic_insert — port LOGIC not signature.** Crate signature takes `Entry{value:String}` (dead shape). Port capacity-check semantics (used_bytes delta, CapacityExceeded) into src-shaped `insert(ip, Value::IpRecord, …)`. Fixed-size Value ⇒ zero-delta replacement logic holds.
9. **Protocol crate = superset of src/ipc types.** `Message{version}+Body+Request+Response` mirrors src/ipc/mod.rs enums + adds versioned envelope + PROTOCOL_VERSION. src/ipc ignores it today. DECISION: adopt protocol crate in Phase 4 — ipc glue imports its types; preserve serde `tag="type", rename_all="snake_case"` attrs exactly (wire compat with deployed CLIs).
10. **consensus/compliance survive merge.** Consensus = 16-line stub holding `Arc<Store>` (shape-agnostic). Compliance uses only `BlockReason` (fixed by #1). Both stay in workspace, fix-forward.
11. **learning crate: stale `ramshield-types` dep** — no actual usage found. Drop dep in Phase 6.
12. **drain_threat_sample already in src TrafficCounters** — src forecasting's racy pop+push-back is unused-method rot. Task 3.4 = call own method, no new code.
13. **DashboardSnapshot identical** both sides. Metrics merge verbatim-safe.

Verdict: plan structurally sound; corrections folded into tasks below (#1→Task 1.1, #3+#7→Task 3.1, #4→Task 3.2, #8→Task 2.2, #9→Task 4.3).

## Integration Matrix (the core of this plan)

Per module: BASE = fuller/newer impl kept nearly verbatim. PORT = concrete pieces taken from the other side. Neither side is discarded wholesale.

| Module | BASE | PORT from other side | DELETE |
|---|---|---|---|
| types | crate skeleton (`events.rs`, `time.rs`, `IpNetwork`) | `BlockDecision` from src/detection; `ConnectionEvent` already in crate events.rs — verify field-identical to src's, else src wins (IPC wire compat) | crate `command::Command` enum + `EnforcementCommand` (superseded by src flat `EnforceCommand{action}` — wire compat with live IPC clients) |
| storage | **src** sharded `Store::new(shard_count)`, `IpRecord`/`SubnetRecord`, `Value` inline-64, `TrafficCounters` | crate: `Wal` (701 LOC, LSN/checkpoint/replay/lz4), `BlobStore`, `atomic_insert()` (RAM-capacity-enforced insert — src insert lacks cap check), `used_bytes`/`blocked_count` AtomicU64 tracking (precise bytes vs src's `ram_limit_mb` knob) | crate `Entry`/`SubnetEntry`/`Store::new(ram_limit)` (subsumed), `ttl_wheel.rs` (11-line stub) |
| detection | **src** `DetectionEngine` full pipeline (BloomFilter, workers, flush) | crate `batch.rs` superset: IPv6 /64 `subnet_key_v6`, `subnet_key → (u128, IpNetwork)`, saturating status bucket; rate_tracker identical | crate stub `detection/mod.rs` (`pub use ramshield_detection::*;` — circular no-op) |
| enforcement | **src** sync actor: TTL expiry loop, dedup window (`processed_decisions`+`processed_order`), `blocked_ips` set, real `AyaXdpApplier` wiring | crate: **WAL-first ordering** — `Option<Arc<Wal>>` injected, append `WalEntry::BlockIp/UnblockIp` BEFORE storage mutation, return `wal_lsn` in `EnforceResult`; crate's `&self` trait methods (Arc-shareable, drop `&mut self`) | crate async-trait generic `EnforcementService<X>` run-loop (older design); crate `main.rs` if standalone binary stub |
| forecasting | **src** behavior (Holt-Winters, entropy, preemptive_block semantics) | crate: `drain_threat_sample()` primitive — replaces src's racy pop+push-back dance on SegQueue; crate's all-zero counts guard (more precise than `len()<2`) | crate copy of ForecastEngine; `pattern_learner` field (dead_code, unwired — YAGNI) |

| config | **src** (XdpConfig, ConfigHandle hot-reload) | crate `StorageConfig` ONLY if merged storage needs `ram_bytes` config knob — decide at Task 3.5 | crate copy |

## Risks

1. **Storage merge** — field mapping Entry↔IpRecord must be done with both files open (Task 2.1 mandatory read-first). Wrong merge loses perf work or durability.
2. **Serde wire compat** — EnforceCommand/ConnectionEvent/WalEntry verbatim; additive-only changes (`wal_lsn` w/ `#[serde(default)]`).
3. **Trait `&mut self`→`&self`** may force interior mutability in appliers — AyaXdpApplier likely already needs it for map handles; contained to xdp.rs.
4. **axum 0.8 route syntax** silently changes matching — enumerate all routes in tests.
5. **XDP/otel features** compile-checked only; runtime validation needs privileges — hand to user.
6. Rollback: branch + per-phase commits; `git checkout main` escapes.

## Follow-ups (out of scope)
- consensus (openraft 0.8), learning, compliance: unused by binary — deletion audit separately (consensus/compliance stay fix-forward per check #10; learning loses stale types dep, check #11).
- ttl_wheel: was a stub; if TTL-at-scale needed later, real implementation goes in ramshield-storage.

## Masters-philosophy gates applied to this refactor
- Ownership-is-API: subnet key stays raw `u128` + IpNetwork metadata (no newtype yet — one consumer family; newtype when v6 policy logic lands).
- Zero-cost: capacity check via existing AtomicU64 delta — no lock added to insert path.
- Errors-are-values: CapacityExceeded surfaces as Result, not panic/log-and-continue.
- Minimal-API: merged Store drops crate's `iter()`/`set_threat_sample()`/`atomic_increment()` (zero consumers after merge).
- Tooling: every task gate = clippy `-D warnings`; final gate adds `cargo audit`.
