# Install

## Binary

Download the release asset for your architecture and its checksum file.

```bash
sha256sum -c ramshield-<version>-<arch>.sha256
chmod +x ramshield-<version>-<arch>
sudo install -m 0755 ramshield-<version>-<arch> /usr/local/bin/ramshield
ramshield --version
```

## Verify signed release

```bash
cosign verify-blob   --certificate ramshield-<version>-<arch>.pem   --signature ramshield-<version>-<arch>.sig   ramshield-<version>-<arch>
```

## Configure and run

```bash
cp config.baseline.toml config.toml
# edit xdp.enabled, xdp.interface, xdp.mode
sudo /usr/local/bin/ramshield --config config.toml
```

SBOM is generated by `scripts/generate_sbom.py`. See `docs/RELEASE_GATE.md`.

## Before public claims

Run `docs/REPRODUCE.md` and record the environment.
