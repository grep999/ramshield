# Benchmark protocol

Record: commit SHA, kernel, CPU model, cores, RAM, rustc, XDP mode, warmup, session count, raw CSV/JSON.

E2 gate: five sessions, raw data attached, environment recorded, variance reported.

Current public figures are historical single-run E1. Raw data is not in-tree. Do not upgrade the evidence class by editing a label.

Commands are in `docs/REPRODUCE.md`.
