## Why it exists

Nine workspace crates need to share the same data structures — connection events, enforcement commands, error types, IP network abstractions. Without a shared type crate, each crate would define its own versions, creating conversion boilerplate and drift. `ramshield-types` is the single source of truth for every struct that crosses crate boundaries.

## What it defines

### ConnectionEvent — the fundamental data unit

```rust
pub struct ConnectionEvent {
    pub src_ip: IpAddr,
    pub upstream_ip: IpAddr,
    pub status: u16,
    pub response_time_ms: u64,
    pub timestamp_ns: u64,
}
```

Created by the IPC server when it parses a client `ConnectionReport`. Fed into the detection engine's channel. The detection crate never creates these — it only consumes them.

### EnforceCommand — the decision payload

```rust
pub struct EnforceCommand {
    pub id: Uuid,              // unique decision ID (dedup key)
    pub action: EnforceAction,
    pub ip: IpAddr,
    pub ttl_secs: Option<u64>,
    pub reason: BlockReason,
    pub source_ip: IpAddr,     // which client triggered this
    pub source_port: u16,
    pub actor: String,         // "detection", "forecasting", "manual"
}
```

This is a struct, not an enum. Every field is always present — the `action` field distinguishes block from unblock, and `reason` explains why. The `id` field is a UUID generated by the detection/forecasting crate; enforcement deduplicates on it.

### EnforceAction — block or unblock

```rust
pub enum EnforceAction {
    Block,
    Unblock,
}
```

Two variants. No "pause", no "throttle", no "rate-limit" — those would require the enforcement service to maintain per-IP state machines. The design keeps enforcement stateless: it receives a command, applies it, and forgets it.

### EnforceResult — what happened

```rust
pub struct EnforceResult {
    pub success: bool,
    pub error: Option<EnforcementError>,
    pub message: String,
}
```

Returned to the IPC client after a manual block/unblock command.

### BlockReason — why it was blocked

```rust
pub enum BlockReason {
    RateLimit,
    SubnetBurst,
    PulseWave,
    Manual,
}
```

Maps to stable strings for wire protocol and Prometheus labels: `"rate_limit"`, `"subnet_burst"`, `"pulse_wave"`, `"manual"`. `from_reason_str()` provides reverse mapping.

### IpNetwork — CIDR representation

```rust
pub struct IpNetwork {
    pub addr: IpAddr,
    pub prefix_len: u8,
}
```

`ipv4_subnet(ip)` returns the `/24` containing the IP. `ipv6_subnet(ip)` returns the `/64`. `pack()` / `unpack()` convert to/from `u128` for use as `DashMap` keys in the subnet table. `contains(ip)` checks membership without allocation.

### BoundedVecDeque — fixed-capacity ring buffer

```rust
pub struct BoundedVecDeque<T> {
    inner: VecDeque<T>,
    cap: usize,
}
```

Used for status code history, event ring buffers, and block logs. O(1) push with automatic eviction of the oldest element when at capacity. No heap reallocation after initial capacity.

### Error Types

```rust
pub enum RsError {
    NotFound(String),
    CapacityExceeded { limit_mb: usize, used_mb: usize },
    Parse(String),
    Io(String),
    Storage(String),
    Protocol(String),
    Enforcement(String),
}

pub enum EnforcementError {
    Wal(String),
    Storage(String),
    Xdp(String),
    AlreadyProcessed,
    Deduplicated,
}
```

`RsError` is the top-level error type for the entire system. `EnforcementError` is specific to the enforcement crate — it distinguishes WAL failures from XDP failures from deduplication (which is not an error, just a no-op).

### Durability — WAL write mode

```rust
pub enum Durability {
    NoSync,
    Fsync,
    Fdatasync,
}
```

Controls how `Wal::append()` syncs to disk. `NoSync` for benchmarking, `Fdatasync` for production, `Fsync` for financial environments.

## Uniqueness

**EnforceCommand is a struct, not an enum.** Most DDoS systems model enforcement as a two-variant enum (`Block { ip, reason }` / `Unblock { ip }`). RamShield uses a flat struct with all fields present always — simpler to serialize, simpler to deserialize, no match arms to maintain. The `action` field does the work the enum variants would do.

**IpNetwork::pack() for DashMap keys.** IP networks can't be `DashMap` keys directly (no `Hash` impl for `IpAddr + prefix_len`). `pack()` compresses them into a single `u128` — enabling O(1) subnet lookups without allocation.

**BoundedVecDeque with zero reallocation.** Pre-allocated to capacity on construction. Push never reallocates. This matters in the detection hot path where thousands of these are created per second.

## Dependencies

**Reads from:** `uuid`, `ipnet` (for CIDR validation).

**Written by:** nothing — this crate has no logic, only types.

**Read by:** every other crate in the workspace.
